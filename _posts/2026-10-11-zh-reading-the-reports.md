过去一年里，我的工作形态变了，而我是等它变完了才察觉的。以前我写代码、读报错；现在我写要求、读报告。代码照样在写，只是敲键盘的不是我。

听上去像升职，顺利的日子里它确实是。但这件事成立有个前提：协作方式得是设计过的。放任不管的话，agent 会产出大量自信、合理、前后自洽的工作，然后把项目悄悄带往一个错误的方向——而你一个星期都不会发现。等发现的时候，你要 debug 的已经不是代码，是一周的决策。

下面五条是我用来避免这件事的规矩。没有一条是巧妙的，基本上都是你对一个新合作者会做的事，只不过要写下来——因为 agent 不记得昨天那场争论。

## 一、第一句提示词之前，先把分工定下来

不是"你写代码我审"——这太模糊，落不了地。要具体到：谁定研究问题，谁对实验设计负责，谁有权改评价指标，谁判断一个结果够不够格被往上搭，以及 agent 的权限到哪儿为止。

我把这些写在两份文档里，一份协作手册、一份工作规范，开一个新 session 先把它们指给 agent。这件事头十分钟像在搞官僚主义，然后替你省下一周。它防的失败很具体也很贵：你让 agent 把一个数提上去，它就会把那个数提上去——包括悄悄改掉这个数在衡量什么。如果没人写明"指标归我管"，那不叫越界，那叫一个没分配的决策权；而没分配的决策权，总是落到正在动的那一方手里。

## 二、在需要之前，先把汇报格式定死

这是单位投入回报最高的一条，也是最常被跳过的一条。分三块：汇报什么、怎么写、什么时候报。

**每份报告必须包含的六项**，按顺序：

1. 上一轮我提的要求和反馈是什么
2. 这一轮实际做了什么
3. 结果是什么，包括任何意料之外的发现
4. 这说明了什么——结论要作为结论写出来
5. 如果有多条路，分别是什么
6. 推荐的下一步

最值回票价的是第一项。把要求复述一遍，是我发现"我们在做两件不同的事"的办法，而且是在一行字里发现，而不是在读完六段关于错误问题的出色工作之后。

**怎么写。** 信息密度高，不要客套话；还有一条是我必须明确提出来的：不要用没解释过的缩写，不要把术语当速记用。agent 写给 agent 看的时候压缩得很狠。写给我的时候，它应该是在给一个刚从门外进来的同事做简报，而不是给全程在场的人记会议纪要。

**什么时候报。** 四档，这四档分不清，agent 要么没用，要么烦人：

- **直接做，不用说。** 格式整理、改名、显而易见的重构，一条命令能撤回的事。
- **先做，做完报。** 计划之内的事，我想知道，但不需要我提前批准。
- **先问，再做。** 任何改动设计、指标、数据或方向的事。任何烧钱的事。任何撤回起来很麻烦的事。
- **立刻打断我。** 出现了和计划所依赖的某个假设相矛盾的结果。这种不能等到这一批跑完再说，因为它每多等一小时，就多一小时的工作是搭在一个我们已经知道有问题的地基上。

## 三、拿到报告，用审稿人的眼睛读，不要用客户的眼睛读

这里的典型失败是"为了放心而读"。报告写得漂亮，结论也鼓舞人心，于是你说"很好，继续"——而你刚刚批准了一条你根本没检查过的推理链。

我试着依次形成这几个判断：

- **印象。** 在评判任何具体内容之前：这东西给我的感觉是扎实的还是赶出来的？是干净，还是干净得有点可疑？
- **尝试充分吗？** 不是"成没成"，而是"这个尝试的强度够不够让一个否定结果说明问题"。只试了一组超参数的失败实验，不构成证据。
- **做对了吗？** 它描述的这件事，真的在检验它声称要检验的东西吗？
- **结论站得住吗？** 大部分缝隙都在这儿。工作本身通常没问题，从结果跨到结论那一步，才是自信跑到证据前面的地方。
- **推荐合理吗？** agent 有很强的惯性，倾向于沿着当前这条路继续走。它推荐的下一步，几乎总是上一步的精细化。
- **是不是需要换一条路？** 这个问题只能我来问。闭环里的任何人都不会问它。

## 四、让第二个模型读这份报告

我会把 agent 的报告粘给另一个模型——我用 GPT——让它先审一遍，然后我再写自己的反馈，最后把两边合成一份回复发回去。

三个原因，第一个有点不好意思承认：

**报告太密了。** 它是写给一个脑子里装着全部上下文的人看的，而我有些天不是那个人。第二个模型会把它拆开讲一遍，而"拆开讲"的过程里，我常常就是在那儿发现某一步其实推不出来。

**新读者能看见洞。** 一个对前六小时工作没有任何投入的审稿人，更容易注意到那个没验证的假设、那条缺失的基线、那个其实不对等的对比。

**两个模型掉进的局部最优不一样。** 这才是真正的理由。一个 agent 在一个问题上做久了会形成沟槽，我也会；而因为我整周都在读它的报告，我们俩的沟槽现在是同一条。引入一个没参与过这段对话的模型，是我知道的最便宜的"获得外部视角"的办法。

## 五、不懂的东西，当场去补

遇到一个我其实不懂的概念——不是"听说过"，是懂——我会停下来去学。不是之后，是当下。

不这么做会出两件事。第一：我会误判好的工作。agent 试了一个正确但我不熟悉的方法，我评估不了，于是我做所有人面对看不懂的提案时都会做的事——要一个更保险的方案。一个正确的尝试，死于审稿人不够格。第二件更糟，而且看不见：我的知识会变成搜索空间的天花板。我没法要求一个我从没听说过的方法。agent 的探索大致只会走到我还跟得上的地方，而我永远不会知道那个半径之外有什么，因为没有任何机制会汇报"那些从未被提出的选项"。

---

**有一点我想白纸黑字写下来。** 这整套做法假设人这边是带着东西来的：领域知识、足够闻出一个结果虚不虚的经验、品味，以及把"真发现"和"讲得好的发现"区分开的判断力。上面每一条规矩，都只是让这份判断力用得更高效。没有一条能生成它。对一个在这个领域里毫无积累的人，这套流程不会让他更快地做出好研究——只会让他更快地做出听上去很有把握的错研究，并且顺手拆掉了本来可能拦住它的那点阻力。

## 这五条规矩共同假设了什么

把它们再读一遍，注意共同点：每一条都把人放在同一个位置上——定方向、判断一次尝试够不够格、决定接下来怎么走。agent 生产，我评估。

这个分工看起来很稳。这篇文章剩下的部分，我想用来讲讲我为什么不确定它稳。

### 到底还剩下什么

以我的位置看——一个博士生的视角，不是劳动经济学家的——没有被挪走的工作是很短的一列：

- 想出那个不在任何人清单上的想法：从 0 到 1。
- 拿领域知识和经验去判断已有的 n 个方案。
- 给出没人提过的第 n+1 个。
- 节奏与方向：知道什么时候加码、什么时候放弃、什么时候整个框架就是错的。

让我在意的是，这四件事全是判断力，而判断力恰恰是唯一一样你没法"一开始就有"的东西。它是沉积物。它来自把事情做砸、察觉到、再做一遍。

### 不舒服的那部分

如果判断力是沉积物，那问题就变成：是什么在沉积它。诚实的答案是下面那几级台阶上不体面的活儿。认真把论文读完。写出那版很烂的初始实现。跑一个因为愚蠢理由而失败的实验。

而这一层，正是现在被交给 agent 的那一层。

斯坦福数字经济实验室的薪资数据研究，发现最明显的效应恰好落在这一段：22 到 25 岁、身处 AI 高暴露岗位的年轻人，就业水平比低暴露岗位的同龄人低约 19%，而同样岗位上经验丰富的人身上没有可比的缺口；并且下滑主要来自"少招人"而不是"裁人"。往一个方向读，这是好消息：有经验的人没事。往另一个方向读，它描述的是一架被抽掉底下几级横档的梯子，然后要问：下一批"有经验的人"打算从哪儿来。

我不认为这件事有定论。那是一篇基于两年数据的工作论文。但我也没法靠指出这一点，就让这个问题消失。

### 列昂惕夫的那个问题

1983 年，华西里·列昂惕夫——拿过诺贝尔经济学奖，而且素来不以耸人听闻著称——把这种担忧推到了最锋利的形式。他说，随着机器接管越来越多的事，人作为最重要生产要素的地位，注定会像马在农业中的地位那样被削弱：先是减少，然后被拖拉机彻底消灭。

让这个说法难以打发的，恰恰是人们通常用来打发它的那句话：*新技术消灭岗位，但也创造新岗位。* 这是真的。在马的数量崩塌的那整段时间里，这句话同样是真的。汽车时代创造了海量的新岗位，其中没有一个是给马的。"新工作会出现"和"被替代的那一方会去做新工作"是两个不同的命题，只有前一个是规律。

高盛在 2026 年 1 月就着这个问题算了一遍，把列昂惕夫的情景当作要检验的极端情况。他们的估计是：大约四分之一的工作小时暴露在自动化之下，整个采用期内 6%–7% 的岗位被替代，失业率峰值上升约 0.6 个百分点——大概一百万人。有破坏性，但不是末日。他们乐观的依据是历史：今天只有约 40% 的劳动者所在的职业在 85 年前就存在，而数以百万计的人如今在计算机、电商、内容这些一代人之前还不存在的岗位上工作。

### 但这还不算完

最诚实的反方砝码，来自那位把"新岗位会出现"这件事量得最仔细的经济学家，而且他的结论是两头都砍的。

David Autor 和合作者发现，2018 年美国约 **60%** 的就业，落在 1940 年还不存在的职业名称里——这是乐观一方最强的版本，而且比大多数乐观者引用的数还大。但同一项工作把两股力量分开了：**自动化**，把任务从人手里拿走；**增强**，创造出新的任务。而就净值而言，1980 年之后自动化跑在了前面。1980–2018 年间自动化对就业的负向效应，是 1940–1980 年间的 **两倍多**；与此同时，增强的正向效应变化要小得多。

所以那句让人安心的话和那句让人不安的话都是真的，它们只是在说两件不同的事。新工作确实在持续出现。而**比例**——消灭多少对创造多少，多快，以及同一批人能不能从这头走到那头——在过去四十年里一直在往不舒服的方向移动，这还是在这一轮之前。

对我来说，这才是真正的问题。不是"会不会有新岗位"，会有。而是：这一轮究竟更像马车变汽车——车夫还有地方可去——还是更像马，行业空前繁荣，而原来的那一方根本不在剧本里。

### 「我们不是马」最有力的论据，不是经济学论据

Brynjolfsson 和 McAfee 正面回应过列昂惕夫，他们那份"人和马的区别"清单值得坐下来看看，因为重量落在哪里很有意思。有些理由是关于能力的——灵巧、常识、人对人的那些只能由人满足的需求。这些是真的，也恰恰是正在缩小的那些。

真正耐久的是另一类。人拥有几乎全部财富，所以人可以再分配它。人投票，可以集体决定什么被允许。还有，人可以为自己在经济上变得无关紧要而抗议——而他们提醒说，马从来没有抗议过。

也就是说：「人不会步马的后尘」最有力的论据，不是我们不可替代，而是我们拥有东西、并且说得上话。这是个真实而且相当大的区别。但它同时是一个对经济学问题给出的政治学答案，而政治学答案属于那种必须主动争取、不能被动依赖的东西。

### 我真正会盯着看的几件事

我没有结论。我有的是一组我认为承重的问题，与其假装其中哪一个已经解决，不如就让它们开着：

- **最底下那级台阶会以另一种形式回来吗？** 以往每一轮最终都长出了新的入口。现在是正在长，还是我们已经在一个缺口里待了两年，而它会一直是个缺口？
- **判断力能用别的方式养出来吗？** 如果过去生产判断力的那套学徒制正在被自动化，有没有替代品——还是说"有经验的人没事"是一句有保质期的话？
- **比例在往哪边走？** Autor 的测量只到 2018 年。真正有意思的数字是 2020–2030 年间自动化对增强的比值，而那个数要好几年后才拿得到。
- **最后是谁拥有那个干活的东西？** 如果人和马之间那个耐久的区别是我们拥有资本、并且能投票，那么所有权的分布就不再是个旁枝问题，它就是主问题。
- **还有一个我能动手的：** 我积累判断力的速度，有没有快过那些生产判断力的任务消失的速度？

最后这条是清单上唯一属于我自己的。这篇文章开头那五条规矩，说到底就是我对它给出的回答——一种使用 agent 的方式，让我尽量待在判断力被积累的那个位置上，而不是只被消耗的那个位置上。

这个位置还能坐多久，我不知道。但比起舒舒服服地不问，我宁愿坐在上面，然后被证明想错了。

## 本文要点

1. **先设计协作，再开始工作**——角色、边界和权限写下来，因为没分配的决策权总会落到正在动的那一方手里。
2. **提前把汇报格式定死**——六个必填项、高信息密度、不用没解释的术语，外加四档清晰的时机：直接做、做完报、先问再做、立刻打断。
3. **用审稿人的眼睛读，不要用客户的眼睛读**——工作本身通常没问题，从结果跨到结论那一步才是自信超过证据的地方。
4. **引入第二个模型**——不是为了更好的答案，而是因为你和你的 agent 已经在同一条沟槽里待了一整周。
5. **不懂就当场补**——你的知识是 agent 搜索空间的天花板，而没有任何机制会汇报那些从未被提出的选项。
6. **这套方法只消耗判断力，不生产判断力**——所以真正敞着的问题是：那些生产判断力的工作，还在不在。

<p style="font-size: 1.4em; font-style: italic; text-align: center; margin: 2rem 0;">新工作会不断出现。它会不会为你而出现，是另一个命题。</p>
